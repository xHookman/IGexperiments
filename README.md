# IGExperiments

🔓 **Unlock Instagram's Developer Options!** 🚀✨  
IGExperiments is a module that unlocks Instagram's hidden developer options, giving you access to advanced features like **White Hat settings** (enables SSL unpinning), **Test User mode**, and much more.

## Features

- Enable Developer Options in Instagram on both rooted and non-rooted devices.
- **Auto Mode** supports all compatible Instagram versions from Instagram version 340+.
- Please Use it on Alpha and Beta versions only!

---

## Installation (Rooted & Non-Rooted Devices)

1. **Download an Instagram APK** from [APKMirror](https://www.apkmirror.com/apk/instagram/instagram-instagram/).  
2. Install the downloaded APK.  
3. Proceed with the instructions for your device type (rooted or non-rooted).

---

### ✅ For Rooted Devices (LSPosed Required)

1. Open Instagram and **sign in** to your account.  
2. Install the module and activate it using **LSPosed**.
3. Force stop Instagram after activation. (You can use the restart button within the module)
4. Open Instagram again and **long-press the home button** to access Developer Options.

---

### ✅ For Non-Rooted Devices (via LSPatch)
**Please Note!**
Use LSPatch fork by [JingMatrix](https://github.com/JingMatrix/LSPatch).
1. Patch the installed Instagram APK using **LSPatch** in **Local Patch Mode**.
2. Open Instagram and **sign in** to your account.  
3. Go back to **LSPatch** and enable the module for Instagram.
4. Force stop Instagram and restart it.
5. Open Instagram and **long-press the home button** to access Developer Options.

---

## What's next?

1. Open **Developer Options** > **MetaConfig Settings & Overrides**.
2. Search for **employee**.
3. Enable the following options:
   - **is employee**
   - **employee options**
   - **is employee or test user**
4. For **rooted users**, go back to **LSPosed** and disable the module for Instagram after enabling the options.  
   For **non-rooted users**, go back to **LSPatch** and disable the module for Instagram after enabling the options.

---

## Updating Instagram

1. Download a newer version of Instagram from **APKMirror**.
2. Install the new APK on your device.
3. **For non-rooted devices**, patch the new APK using **LSPatch** in **Local Patch Mode**.
4. Repeat the steps under **Installation** to re-enable developer options.

## FAQ

### The module doesn't start.

Open a ticket and provide your device name, OS version, root status, and the logs from LSPosed (if rooted).

### Instagram is taking a long time to open.

This is normal. Once you’ve accessed Instagram, follow the guide to enable the **Developer Options**. After that, **disable the module** in your manager (LSPosed or LSPatch) to improve the app’s loading speed.

### Developer options are not showing up.

1. Ensure you've installed a compatible Instagram version (340+).
2. Ensure the module is enabled in **LSPosed**, **LSPatch**.
3. Deactivate and reactivate the module if necessary.
4. If none of the above works, check the logs in **LSPosed** and open a ticket with the log details (if rooted).

### Where is the home button?

The **Instagram home button** is the one at the bottom of the app, not the home button on your phone.
